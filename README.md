# Jev as a Judge

Intro to Jev.

## Setup


```sh
curl -LsSf https://astral.sh/uv/install.sh | sh # installs uv
uv sync # install dependencies (creates `.venv/` automatically)
uv run main.py # run scripts
source .venv/bin/activate # Optional, activate venv to use `python` directly
```
